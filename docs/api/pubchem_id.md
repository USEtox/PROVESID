# PubChemID

Offline: the PubChem compounds that carry a CAS number, from `pubchem_id.db`.
`provesid.pubchem_ftp` builds that database from PubChem's FTP site. See
[Installing the offline databases](../guide/datasets.md#pubchem-built-from-the-ftp-site-or-a-prebuilt-copy)
and [Using the local databases directly](../guide/local-databases.md#pubchem-properties-without-the-network).
